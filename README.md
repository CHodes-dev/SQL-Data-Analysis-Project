# SQL Data Analysis Project

## Project Overview

This repository contains the Exploratory Data Analysis (EDA) and Advanced Data Analysis projects developed as a continuation of my previous SQL Data Warehouse Project.

The purpose of these projects is to explore structured data, identify patterns and trends, analyze business performance, and generate insights using SQL. The analysis builds upon the data preparation and integration processes established in the Data Warehouse Project.

The complete workflow covers three main stages:

1. Data Warehouse: Organizing, integrating, and preparing data for analysis.
2. Exploratory Data Analysis (EDA): Understanding data characteristics, exploring dimensions and measures, and identifying initial patterns.
3. Data Analysis: Performing deeper analytical queries to evaluate changes over time and uncover meaningful business insights.

The analytical findings are intended to support the development of a business performance report and an interactive Power BI dashboard.

**Project Objective**
- Explore and understand structured datasets using SQL.
- Identify patterns, trends, and changes in business performance.
- Apply advanced SQL techniques to answer analytical questions.
- Translate query results into meaningful business insights.
- Build a foundation for business reporting and performance visualization.

## Project Requirements

**Prerequisites**
To explore or reproduce the analysis, the following are recommended:
- SQL Server Express installed and configured.
- SQL Server Management Studio (SSMS) for executing SQL scripts.
- Git for cloning and managing the repository.
- Access to the CSV datasets included in the repository, subject to their applicable license.

**Knowledge Requirements**
A basic understanding of the following concepts will help users follow the project:
- SQL querying and filtering.
- Aggregate functions and grouping.
- Joins, Common Table Expressions (CTEs), and subqueries.
- Date and time analysis.
- Window functions.
- Exploratory data analysis and business performance metrics.
